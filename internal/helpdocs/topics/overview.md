# Getting started

Whodis accepts a domain, URL, IP address, network, or ASN. Start with the smallest operation that answers your question.

- **Lookup** — registration identity through RDAP, WHOIS, or RWhois.
- **Inspect** — registration plus a practical public DNS inventory.
- **Diagnose** — DNS, delegation, reachability, HTTP, TLS, mail, and advertised services.
- **Investigate** — hosting, network ownership, technology evidence, homepage observations, and research pivots.

```text
whodis example.com
whodis inspect example.com
whodis diagnose example.com
whodis investigate example.com
```

The native desktop buttons run the same engine as these commands. Partial results are intentional: one unavailable registry or probe does not erase evidence collected elsewhere.

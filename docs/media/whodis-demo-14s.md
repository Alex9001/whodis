# WhoDis video demo

[Watch or download the 14-second video](whodis-demo-14s.mp4).

1920×1080, 30 fps, H.264 video with stereo AAC audio. Published on 2026-10-07.

## Product footage

The opening types `whodis example.com` and displays the actual default Pretty renderer's Registration, Contacts, Timeline, Source and DNS panels. The two GUI shots show complete native Qt windows for Investigation and Stack, including the operation controls and evidence panel. The ending uses the production investigation renderer's terminal output.

Terminal frames are actual xfce4-terminal/VTE captures. The GUI is captured at 2× display scale and reduced as a complete window, with no component crops. All domain records, contacts, IPs and website findings are labelled synthetic demonstration data for reserved example domains; these are not live network lookup results.
